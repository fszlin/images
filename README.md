# images

Dockerfiles for my container images, published to GHCR as `ghcr.io/fszlin/<image>`.

| Image | Description |
| --- | --- |
| [opencode](images/opencode) | opencode CLI |
| [devops-agent](images/devops-agent) | opencode plus DevOps tooling |

Each image lives in `images/<name>/`. Adding a directory with a Dockerfile adds it to CI.
